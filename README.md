# CRM Frontend

Enterprise WhatsApp Lead Management & Production Workflow Automation CRM frontend built with React, Tailwind CSS, Redux Toolkit, and Socket.IO.

## Features

- Role-based protected routing
- JWT authentication with interceptor
- Modular, scalable architecture
- Dashboard, leads, design, printing, delivery, reports, and logs pages
- Real-time notification engine with Socket.IO

## Setup

1. `cd frontend`
2. `npm install`
3. `npm run dev`

## Structure

- `src/components` — reusable UI components
- `src/layouts` — page shells and navigation
- `src/pages` — application screens
- `src/redux` — store and slices
- `src/services` — API service layer
- `src/socket` — Socket.IO setup
- `src/routes` — routing and guards
